# Pizza Inventory Servlet Exercise

A Java Servlet learning project with inventory, producer and consumer classes.
This is a backend exercise rather than a finished pizza-ordering product.

## Structure

- `src/com/servlet/`: Java inventory and servlet classes.
- `WebContent/WEB-INF/web.xml`: web-application configuration.
- Eclipse project files: original development-workspace configuration.

## Local setup

Import the project into an IDE supporting Java web applications. Configure a
JDK and a servlet container compatible with the imports in the source. The
repository has no Maven or Gradle dependency manifest, so configure the Servlet
API and runtime manually before building and deploying to a local container.
